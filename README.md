# Listening Log

Personal archive of key themes, quotes, and anecdotes from the audiobooks I listen to on Audible, built with [Zensical](https://zensical.org/).

## Structure

- `docs/books/` - Structured chapter notes, key themes, quotes, and anecdotes by book.

## Local Preview

```bash
uvx zensical serve
```

Or with a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
zensical serve
```
